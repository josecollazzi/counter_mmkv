# Tutorial: Flutter Integration with Native Widgets

This tutorial demonstrates how to integrate Flutter with native home widgets for Android (using Kotlin) and iOS (using Swift). 
You'll learn how to enable seamless communication between your Flutter app and native widgets while efficiently sharing data.

## Overview

We will use the following tools and libraries to achieve this integration:

- **Home Widget Package:** Facilitates communication between Flutter and native home widgets.
- **MMKV Library:** A high-performance storage solution for sharing data between the app and native widgets.

## What You'll Learn

1. **Android Integration**: Setting up a native widget for Android using Kotlin.
2. **iOS Integration**: Setting up a native widget for iOS using Swift.
3. **Communication**: Establishing two-way communication between the Flutter app and the widgets.
4. **Data Sharing**: Persisting and sharing data using the MMKV library.
